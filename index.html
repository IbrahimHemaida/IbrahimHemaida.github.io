Selected Work

Nabed Connect and Nabed TV: healthcare IoT ecosystem

  • Challenge: a nationwide healthcare platform holding 99.9% content availability across restricted clinical networks.
  • Approach: an offline-first system with local persistence and MQTT device synchronization, plus a custom kiosk launcher with hardware-level MAC activation.
  • Result: device activation time down 60%, multi-patient session handling improved 30% through a WCAG accessibility-first tablet UI redesign.

RD Labs: AI assistant and caller ID

  • Challenge: modernizing an application with 3M+ users while holding crash rates down and keeping the UI smooth.
  • Approach: led a full migration to Hilt, Coroutines, and MVVM Clean Architecture with modular configurations, and integrated on-device NLP for real-time processing.
  • Result: crash rate down 15% measured in Firebase Crashlytics, average UI jank down 40% measured in Android Profiler and Systrace.

Savvy: smart hotel automation

  • Challenge: automating guest experiences over IoT controls without making the interface harder to use.
  • Approach: integrated PMS and VingCard SDKs over Bluetooth and NFC, wrapped in a UI that stays usable for guests with mobility limitations.
  • Result: automated guest workflows across 5+ luxury properties, service request resolution 35% faster.
